# Feature Specifications

This directory contains architecture plans and API contracts
for features under development.

## Format

Each spec should include:
- **Summary** — one-line description
- **Motivation** — why this feature
- **Architecture** — component diagram, data flow
- **API Contract** — TypeScript interfaces
- **File Plan** — which files to create/modify
- **Acceptance Criteria** — testable outcomes
- **Dependencies** — other specs/tasks this depends on
