## Task Lifecycle

1. **pending** — Defined but not yet started
2. **in-progress** — Agent is actively working
3. **done** — Completed and verified

## Creating Tasks

When a user request is vague, create a task file and request
clarification before implementing.  Tasks should be small enough
to complete in a single session.
